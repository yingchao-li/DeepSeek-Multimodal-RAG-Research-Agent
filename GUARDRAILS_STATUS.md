## Configuration and behavior

- `RAG_MIN_EVIDENCE_SCORE=0.45` gates document-grounded answers. Dense scores are clamped to `[0,1]`; hybrid RRF scores receive a bounded relative normalization in `src/vector_store.py:retrieve` so the same gate can be used without changing ranking. This is a heuristic, not a calibrated probability.
- `RAG_MAX_CALLS=8` caps logical LLM calls per RAG/chat request. The agent's existing lower cap still applies.
- `RAG_AUDIT_PATH=logs/audit.jsonl` and `RAG_AUDIT_QUESTION_MAX_CHARS=200` control the audit file and question truncation. The file is created with user-only permissions where supported. No API keys, full document text or base64 image data are written intentionally.
- When a document-grounded answer abstains, the Streamlit chat record and evaluation adapter expose an empty evidence/source list. General chat remains available without document evidence.

## Test results

`.venv/bin/python -m pytest -q` on 2026-11-05: **60 passed, 1 skipped** in 9.96 seconds. The skipped test is the explicitly opted-in paid API test (`RUN_PAID_API_TESTS=1`); no paid API was called. `pytest` was installed into the existing virtual environment from the already declared `requirements-dev.txt` range. One older UI mock had to be updated to return a citation because uncited answers now correctly abstain.

## Known limitations

- Citation validation checks that a `[S#]` label maps to a retrieved chunk with a source. It does **not** prove that the cited chunk actually supports each claim, nor verify page/figure semantics. This remains the job of the existing answer verifier and human review.
- Injection detection is a small pattern list. It misses paraphrases, obfuscation and instructions hidden in images. Delimiters and prompt wording lower risk but cannot guarantee immunity to prompt injection.
- The default evidence threshold and RRF normalization have not been tuned on a large labelled set. They can reject useful low-scoring evidence or admit irrelevant high-scoring evidence.
- The JSONL audit is currently one record per document RAG, Agentic RAG or general-chat entry-point call. Legacy paper summarization, direct full-text paper chat, data analysis and lower-level utility calls are outside this new audit wrapper. Plain RAG's logged latency starts at answer generation, after retrieval; the Agentic RAG entry point includes retrieval.
- `RAG_MAX_CALLS` counts logical calls through `src/api.py:request`. The OpenAI SDK's own automatic network retries may add HTTP attempts; they are not counted separately. Input characters and maximum output tokens are bounded per call, not by a cumulative session-token budget.
- Audit logging requires a writable destination; an unwritable path emits an `audit_log_unavailable` warning so it does not interrupt the chat. The application has not been validated for clinical or legal use. These tests used mocked responses only and do not establish real-model refusal or citation reliability.
